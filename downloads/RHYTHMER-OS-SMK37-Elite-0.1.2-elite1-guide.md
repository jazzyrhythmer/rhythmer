# SMK-37 Elite firmware preview

This Elite build has passed software package and model checks. Physical Elite
installation, boot and recovery are still awaiting validation.

Back up the keyboard first. Open the matching OS installation page in desktop
Chrome or Edge, connect one keyboard in normal mode and use **Detect Keyboard
& Install**. Use the download buttons when you need the raw firmware file.
If the model is unclear or the device is already in its update loader, the
automatic installer stops before transfer.

For restoration, follow the manufacturer’s instructions and obtain the
matching Elite V016 from [M-VAVE](https://www.sincoaudio.com/product?id=smk-37-elite).
Use the [official workbench](https://open.m-vave.com/smk37-workbench) as directed.
